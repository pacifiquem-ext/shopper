# Transactional email templates

HTML is generated by TypeScript helpers in `email-templates.ts` using the AlignUI-aligned layout in `email-layout.ts`.

| Helper | Use |
| ------ | --- |
| `welcomeEmailHtml` | After signup / store creation |
| `passwordResetEmailHtml` | Forgot password OTP / link |
| `orderConfirmationEmailHtml` | Guest or customer order placed |
| `storeApprovedEmailHtml` | Admin approves a store |

Brand colors match the app primary green (`#1daf61`) and gray neutrals. Wire a mail transport (Resend/SES/SMTP) and call these helpers from the relevant services — do not reintroduce ad-hoc HTML strings in feature modules.
